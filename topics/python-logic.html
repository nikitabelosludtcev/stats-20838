Week 2 · logic

if, for, and a function

A loop does the same thing for every item. A condition chooses a branch. A function packs a plan so you can call it on new data.

Presentation. Python Basics. Conditions, loops, and a small function.

A Boolean value

grade = 18
print(grade >= 18)  # True

A comparison is not a number. It gives True or False. Then and demands that both pieces are True, or is happy with one, and not flips the answer.

if grade >= 18:
    print("pass")
else:
    print("retry")

The colon opens a branch. The indent shows which lines are inside. On the slide grade = 18, the condition is true, and the path prints pass. If it had been 16, the print would be retry.

A loop

grades = [16, 18, 25, 30]
for grade in grades:
    if grade >= 18:
        print("pass")
    else:
        print("retry")

grade becomes 16, then 18, then 25, then 30. For 16 the print is retry. For the others it is pass. The indent on if is required. Without it Python does not see that the fork is inside the loop, and it raises IndentationError.

If you need to keep the results, not only print them:

updated = []
for old in [18, 29, 26, 27]:
    updated.append(old + 1)

append puts a new item at the end of the list. After the loop, updated holds [19, 30, 27, 28]. Plus one to each grade is the slide’s bonus-point example.

A nested dictionary

students = {
    "Kirs": {"best_grade": 29, "course": "corporate finance"},
    "Paula": {"best_grade": 30, "course": "math"},
}
print(students["Kirs"]["best_grade"])  # 29

Two keys in a row. The first picks the person. The second picks a field inside that person’s card. The slide’s mistake: students["best_grade"] looks for the key best_grade at the outer level, where the keys are Kirs, Paula, and Mark. That key is not there, so you get a KeyError.

To lower Kirs’s grade by 2: students["Kirs"]["best_grade"] -= 2. The spelling -= means “read it, subtract, write it back”.

A function separates the plan from the data

The slide asks for list_average without the ready-made function sum.

def list_average(values):
    total = 0
    count = 0
    for v in values:
        total = total + v
        count = count + 1
    return total / count
print(list_average([18, 29, 26, 27]))  # 25.0

def only describes the plan. The plan runs on the line that calls it. return hands the result out. 18+29+26+27 = 100, divided by 4, is 25.

Worked example: the Stone family’s luggage

A dictionary of bag weights. The plane lets you on if each bag is no heavier than the limit and, possibly, if the sum is inside a limit too. The slide warns that checking only sum(weights) < 27 is incomplete. One bag can be 20 kg against a 10 kg limit, while the sum is still small if the other bags are almost empty. You need a loop that looks at every weight, and a separate sum if there is a limit on the total as well.
