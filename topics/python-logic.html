Неделя 2 · logic

if, for и функция

Цикл делает одно и то же для каждого элемента. Условие выбирает ветку. Функция упаковывает план, чтобы его можно было вызвать на новых данных.

Булево значение

grade = 18
print(grade >= 18)  # True

Сравнение не равно числу. Оно даёт True или False. Дальше and требует, чтобы оба куска были True, or довольствуется одним, not переворачивает.

if grade >= 18:
    print("pass")
else:
    print("retry")

Двоеточие открывает ветку. Отступ показывает, какие строки внутри. На слайде grade = 18, условие истинно, путь ведёт в pass. Если бы стояло 16, напечаталось бы retry.

Цикл

grades = [16, 18, 25, 30]
for grade in grades:
    if grade >= 18:
        print("pass")
    else:
        print("retry")

grade по очереди становится 16, потом 18, потом 25, потом 30. Для 16 печатается retry, для остальных pass. Отступ у if обязателен: без него Python не поймёт, что развилка внутри цикла, и выдаст IndentationError.

Если нужно сохранить результаты, а не только печатать:

updated = []
for old in [18, 29, 26, 27]:
    updated.append(old + 1)

append кладёт новый элемент в конец списка. После цикла в updated лежит [19, 30, 27, 28]. Плюс один к каждой оценке — пример слайда про бонусный балл.

Вложенный словарь

students = {
    "Kirs": {"best_grade": 29, "course": "corporate finance"},
    "Paula": {"best_grade": 30, "course": "math"},
}
print(students["Kirs"]["best_grade"])  # 29

Два ключа подряд. Первый выбирает человека, второй поле внутри его карточки. Ошибка слайда: students["best_grade"] ищет ключ best_grade на внешнем уровне, а там ключи Kirs, Paula и Mark. Такого ключа нет, будет KeyError.

Понизить оценку Kirs на 2 нужно так: students["Kirs"]["best_grade"] -= 2. Запись -= значит «прочитай, вычти, запиши обратно».

Функция отделяет план от данных

Слайд просит list_average без готовой функции sum.

def list_average(values):
    total = 0
    count = 0
    for v in values:
        total = total + v
        count = count + 1
    return total / count

print(list_average([18, 29, 26, 27]))  # 25.0

def только описывает план. План запускается в строке с вызовом. return отдаёт результат наружу. 18+29+26+27 = 100, делим на 4, получаем 25.

Решённая задача: багаж семьи Stone

Словарь весов сумок. Самолёт пускает, если каждая сумка не тяжелее лимита и, возможно, если сумма тоже в лимите. Слайд предупреждает: проверка только sum(weights) < 27 неполная. Одна сумка может быть 20 кг при лимите 10, а сумма всё ещё маленькая, если остальные почти пустые. Нужен цикл, который смотрит каждый вес, и отдельно сумма, если лимит есть и на неё.

Что могут показать в MCQФрагмент с for и if, и вопрос «что напечатается». Спокойно идите по элементам слева направо и записывайте печать на бумаге. Не запускайте код в голове «примерно».
