Тетрадь банка: что делает каждая строка

Это не новый материал. Та же таблица, но руками в Python. На экзамене могут показать короткую строку и спросить, что она печатает.

Тетрадь открывает bank.xlsx, смотрит типы и распределения, потом считает SE, интервал и проверку μ = 41. Идите сверху вниз. Комментарии в файле частично на русском, с опечаткой в слове «библиотек»: на смысл это не влияет.

Открыть и посмотреть

import pandas as pd
import statsmodels.formula.api as smf
import numpy as np
bank = pd.read_excel('bank.xlsx')
bank.columns

import приносит готовый набор команд. pandas умеет таблицы, его обычно зовут pd. numpy умеет корень и другие расчёты, его зовут np. statsmodels в этой тетради импортирован, но до модели дело не доходит: это задел. read_excel читает файл в объект bank. bank.columns печатает имена 17 столбцов, от age до y.

bank['marital'].value_counts()
bank['marital'].value_counts(normalize=True) * 100

Первая строка считает людей: married 2797, single 1196, divorced 528. Вторая делит на всех и умножает на 100, получаются проценты: 61,87, 26,45, 11,68. normalize=True значит «дай доли, а не штуки».

bank['marital'].value_counts().plot(kind='bar')
bank['age'].hist()
bank.boxplot(column='balance')

Столбчатая диаграмма для категории, гистограмма для возраста, ящик для баланса. kind='bar' выбирает тип картинки. На экзамене важно узнать имя метода, а не красиво рисовать.

Числа, которые уже знакомы

bank['age'].mean()      # 41.170
bank['age'].median()    # 39.0
bank['age'].std()       # 10.576
bank.describe()

describe() для числовых столбцов печатает count, mean, std, min, 25%, 50%, 75%, max. Оттуда же видно, что медиана balance 444, а mean 1422,66.

От описания к выводу

sample_mean = bank['age'].mean()
age_sd = bank['age'].std()
n = bank['age'].count()
se = age_sd / np.sqrt(n)

Четыре имени. sample_mean хранит x̄. age_sd хранит SD. count() считает непустые строки, здесь 4521. np.sqrt(n) — квадратный корень. Деление даёт SE ≈ 0,157.

lower = sample_mean - 1.96 * se
upper = sample_mean + 1.96 * se

Звёздочка в Python — умножение, не сноска. Получается 40,86 … 41,48.

hypothesized_mean = 41
t_statistic = (sample_mean - hypothesized_mean) / se
critical_value = 1.96
if abs(t_statistic) > critical_value:
    print("Decision: Reject H0")
else:
    print("Decision: Do not reject H0")

abs убирает знак: важно расстояние, а не «моложе или старше». Условие if с отступом: строки с отступом выполняются только если условие истинно. Здесь |t| = 1,08 не больше 1,96, печатается Do not reject H0.

Дальше тетрадь берёт случайные 50 возрастов и строит для них свой интервал. Он шире, потому что n маленькое и SE большое. Конкретные границы в файле (около 36,9–41,9 при среднем 39,44) зависят от того, какие 50 строк выпали. На экзамене не зубрят этот случайный интервал. Зубрят, что при n = 50 шум среднего гораздо больше, чем при n = 4 521.

Частая ошибка в коде= кладёт значение в имя. == спрашивает «равно ли». В проверке гипотезы сравнение написано через >, не через =. Если написать if abs(t_statistic) = critical_value, Python выдаст ошибку.
