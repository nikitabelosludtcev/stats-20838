Week 1 · bank_basics

The bank notebook: what each line does

This is not new material. It is the same table, done by hand in Python. On the exam they may show one short line and ask what it prints.

The notebook opens bank.xlsx, looks at types and distributions, then computes the SE, the interval, and the test of μ = 41. Go from top to bottom. Some comments in the file are in Russian, with a typo in the word for “libraries”. That does not change the meaning.

Open the file and look

import pandas as pd
import statsmodels.formula.api as smf
import numpy as np
bank = pd.read_excel('bank.xlsx')
bank.columns

import brings in a ready set of commands. pandas handles tables and is usually nicknamed pd. numpy handles the square root and is nicknamed np. statsmodels is imported here but the notebook never reaches a model. It is a placeholder. read_excel reads the file into the object bank. bank.columns prints the 17 names, from age to y.

bank['marital'].value_counts()
bank['marital'].value_counts(normalize=True) * 100

The first line counts people: married 2797, single 1196, divorced 528. The second divides by everyone and multiplies by 100, so you get percentages: 61.87, 26.45, 11.68. normalize=True means “give shares, not counts”.

bank['marital'].value_counts().plot(kind='bar')
bank['age'].hist()
bank.boxplot(column='balance')

A bar chart for a category, a histogram for age, a box for balance. kind='bar' chooses the picture. On the exam, recognise the method’s name. You do not have to draw it beautifully.

Numbers you already know

bank['age'].mean()      # 41.170
bank['age'].median()    # 39.0
bank['age'].std()       # 10.576
bank.describe()

describe() prints, for numeric columns, count, mean, std, min, 25%, 50%, 75%, max. From the same printout, the median of balance is 444 and the mean is 1422.66.

From a description to a conclusion

sample_mean = bank['age'].mean()
age_sd = bank['age'].std()
n = bank['age'].count()
se = age_sd / np.sqrt(n)

Four names. sample_mean holds x̄. age_sd holds the SD. count() counts non-empty rows, here 4521. np.sqrt(n) is the square root. The division gives SE ≈ 0.157.

lower = sample_mean - 1.96 * se
upper = sample_mean + 1.96 * se

In Python the star is multiplication, not a footnote. The result is 40.86 … 41.48.

hypothesized_mean = 41
t_statistic = (sample_mean - hypothesized_mean) / se
critical_value = 1.96
if abs(t_statistic) > critical_value:
    print("Decision: Reject H0")
else:
    print("Decision: Do not reject H0")

abs drops the sign. What matters is the distance, not “younger or older”. The indented lines under if run only when the condition is true. Here |t| = 1.08 is not greater than 1.96, so the notebook prints Do not reject H0.

The notebook then draws 50 random ages and builds an interval for them. That interval is wider, because n is small and the SE is large. The exact ends in the file (about 36.9–41.9, with a mean of 39.44) depend on which 50 rows came up. Do not memorise that random interval. Memorise that noise in the mean is much larger at n = 50 than at n = 4,521.

A common miss in the code= puts a value into a name. == asks “are these equal?”. The hypothesis check uses >, not =. If you write if abs(t_statistic) = critical_value, Python reports an error.
