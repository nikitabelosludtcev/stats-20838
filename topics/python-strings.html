Week 2 · strings and slices

Text, methods, and slices

A string is text. A list is a queue of values. Both have positions, and both positions count from zero.

A method returns new text

my_name = "Anna Rossi"
small_name = my_name.lower()
BIG_name = my_name.upper()
print(my_name == small_name)  # False

lower() makes lowercase letters. upper() makes capitals. The original name does not change unless you store the result back into it yourself. == asks whether two texts match. "Anna Rossi" and "anna rossi" do not match, so the print is False.

The slide shows a typical break:

"I will pass " + course + " with " + grade

If grade is the number 29, Python refuses to add text and a number. Turn the number into text with str(grade). The error’s name is worth remembering: TypeError, “these types do not fit together”.

Repeating a piece of text

let_it_be = "let it be, "
chorus = let_it_be * 4

Multiplying a string by 4 does not multiply letters the way numbers multiply. It repeats the text four times. The slide uses this in a phrase exercise.

A slice: from here, up to but not including the end

tv_shows = ["Breaking Bad", "Dark", "The Office", "Stranger Things", "Rick & Morty"]
print(len(tv_shows))  # 5
best = tv_shows[:3]   # the first three
worst = tv_shows[-3:] # the last three

len counts the items. [:3] means “from the start up to index 3, and do not take index 3 itself”, so places 0, 1, and 2. [-3:] means “the last three”. A minus counts from the tail.

The slide’s exercise: from a list of Italian food, take everything except the first two and the last two. If the list has 8 dishes at indexes 0…7, the slice [2:-2] keeps indexes 2, 3, 4, and 5. The end -2 is not included, so the last two drop off, and the first two dropped because you started at 2.

Picture to keepA slice “starts here and stops before that place”. The right edge is not included. That off-by-one is the most common mistake.

A worked slice

Imagine italian_food as: 0 pineapple, 1 pizza, 2 pasta, 3 risotto, 4 gelato, 5 tiramisu. The command italian_food[2:-2] starts at 2 (pasta) and stops before −2. In a list of 6 items, index −2 is place 4 (gelato). So you keep 2 and 3: pasta and risotto. Gelato is the boundary and is not included. If there are more dishes, every middle one comes along.

The exact food list is drawn on the slide, and the PDF text cuts it off. The slice rule does not change, and the rule is what a code question asks.
