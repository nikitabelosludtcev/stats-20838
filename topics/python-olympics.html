Четыре задачи и рабочие приёмы

Это классные головоломки, не отдельные экзаменационные теории. Они тренируют те же приёмы, которые всплывают в коротких вопросах по коду.

Формат на слайде: 15 минут на задачу, без ИИ, несколько верных способов, чистая логика важнее трюка. Ниже решения, которые колода показывает после всех четырёх раундов. Имеет смысл сначала закрыть ответ рукой и предсказать вывод.

1. Убрать решётки

garble = "P#y#t#h#o#n#S#u#x#x#!"

Хрупкий способ: выписать символы по фиксированным чётным местам. Он работает только пока решётка строго чередуется с буквой.

Переносимый способ со слайда:

clean = ""
for char in garble:
    if char != "#":
        clean = clean + char
print(clean)  # PythonSuxx!

Цикл оставляет каждый символ, который не решётка. Если узор сломается, способ всё ещё верен.

2. Общая еда

team_likes = [
    {"pizza", "sushi", "tacos"},
    {"tacos", "ramen", "pizza"},
    {"pizza", "tacos", "salad"},
]
common = team_likes[0] & team_likes[1] & team_likes[2]
print(sorted(common))  # ['pizza', 'tacos']

sorted нужен, потому что множество само порядок не обещает, а печать хочется стабильной.

3. Кто набрал больше 10 за два раунда

round1 = {"Ana": 8, "Leo": 5, "Mia": 7}
round2 = {"Mia": 4, "Zoe": 9, "Ana": 2}
totals = {}
for scores in [round1, round2]:
    for name, points in scores.items():
        totals[name] = totals.get(name, 0) + points

items() отдаёт пары ключ и значение. get(name, 0) значит: если имени ещё нет, возьми 0, не падай. Дальше прибавь очки.

  1. Ana: 8, потом 8+2 = 10.
  2. Leo: 5. Во втором раунде его нет, остаётся 5.
  3. Mia: 7+4 = 11.
  4. Zoe: её не было в первом, старт с 0, затем 9.
  5. Больше 10 только у Mia. Ana ровно на 10, если вопрос «больше 10», она не проходит. Читайте строгость знака > или >=.

4. Анаграммы слова race

Список: care, bake, race, acer, face, rack. Плохой тест set(word) == set(target) найдёт care, race, acer. Но множество стирает повторы: слово racer тоже превратится в набор букв {r, a, c, e} и ложно совпадёт с race.

Общий тест со слайда:

sorted(word) == sorted("race")

Буквы выстраиваются по алфавиту. У race это a, c, e, r. У care то же самое. У racer получится a, c, e, r, r — лишняя r, совпадения нет. У bake буквы другие.
