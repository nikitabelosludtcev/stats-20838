Week 2 · the deck’s olympics

Four puzzles, and the moves that solve them

These are classroom puzzles, not separate exam theories. They train the same moves that show up in a short question about code.

Presentation. Python Basics. The deck’s Python Olympics: four short problems, then the solutions the slides show.

The slide’s format: 15 minutes a puzzle, no AI, several correct ways, and clean logic ahead of a trick. Below are the solutions the deck shows after all four rounds. Cover the answer with your hand first and predict the output.

1. Strip the hashes

garble = "P#y#t#h#o#n#S#u#x#x#!"

A fragile way: copy the characters at fixed even places. It works only while a hash strictly alternates with a letter.

The portable way on the slide:

clean = ""
for char in garble:
    if char != "#":
        clean = clean + char
print(clean)  # PythonSuxx!

The loop keeps every character that is not a hash. If the pattern breaks, the method is still right.

2. Food in common

team_likes = [
    {"pizza", "sushi", "tacos"},
    {"tacos", "ramen", "pizza"},
    {"pizza", "tacos", "salad"},
]
common = team_likes[0] & team_likes[1] & team_likes[2]
print(sorted(common))  # ['pizza', 'tacos']

sorted is there because a set does not promise an order, and you want a stable print.

3. Who scored more than 10 across two rounds

round1 = {"Ana": 8, "Leo": 5, "Mia": 7}
round2 = {"Mia": 4, "Zoe": 9, "Ana": 2}
totals = {}
for scores in [round1, round2]:
    for name, points in scores.items():
        totals[name] = totals.get(name, 0) + points

items() hands you key and value pairs. get(name, 0) means: if the name is not there yet, take 0, do not crash. Then add the points.

  • Ana: 8, then 8+2 = 10.
  • Leo: 5. He is absent from round 2, so he stays at 5.
  • Mia: 7+4 = 11.
  • Zoe: she was not in round 1, so she starts at 0, then 9.

Only Mia is above 10. Ana is exactly 10. If the question says “more than 10”, she does not pass. Read the sign > or >= strictly.

4. Anagrams of the word race

The list: care, bake, race, acer, face, rack. The bad test set(word) == set(target) finds care, race, and acer. But a set throws repeats away: the word racer also becomes the letter set {r, a, c, e} and falsely matches race.

The shared test on the slide:

sorted(word) == sorted("race")

The letters line up in alphabetical order. For race that is a, c, e, r. care is the same. racer becomes a, c, e, r, r — an extra r, so no match. bake has different letters.
