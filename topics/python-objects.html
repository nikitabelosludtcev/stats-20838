Week 2 · Python Basics

Names, lists, and sets

A variable is a name stuck to a value. On the exam they show one line and ask what you get.

Francesco Balocco’s deck promises that by the end you can solve a small problem with no template. For the written exam the closing class is more specific: a multiple-choice question about what the code does. You will not be given software to run.

A name, and assignment

grade = 16
grade = grade + 2

The first line creates the name grade and puts 16 in it. The second reads the current 16, adds 2, and writes 18 back. The old 16 is gone. The sign = is not the “equals” of mathematics. It means “put this here”.

A name cannot contain a space. birth year = 2005 is an error. A working name is birth_year. The slide diagnoses this in 60 seconds: valid name, or not.

A list keeps order and repeats

tv_shows = ["Dark", "The Office", "Dark"]

A list numbers its items from zero. Index 0 is "Dark", index 1 is "The Office", index 2 is "Dark" again. A repeat is legal: two copies of the same show stay as two entries. The order is a ranking. You must not throw it away.

A set keeps unique values

pets = {"dog", "cat", "dog"}

A set folds this into {"dog", "cat"}. The second "dog" disappears. There is no order you can rely on. The curly braces here are not a dictionary: there are no “key: value” pairs inside.

Worked example: years left until 100

birth_year = 2002
current_year = 2026
years_left = birth_year + 100 - current_year
print(years_left)  # 76
  1. No space in the name: birth_year, not birth year.
  2. = stores. If you write ==, Python thinks you are asking a question, not storing.
  3. The slide’s formula is birth year + 100 − current year. For 2002 and 2026 that is 76.
  4. A small check: someone born in 2000 is 26 in 2026, so 74 years remain until 100. The formula gives 2000 + 100 − 2026 = 74. It matches.

A weighted average, not the ordinary one

Grades: marketing101 = 30 on 5 credits, business101 = 26 on 8, math101 = 24 on 5.

The bad habit is (30 + 26 + 24) / 3 = 26.67. Every course weighs the same, even though business is longer.

What you need: (30×5 + 26×8 + 24×5) / (5 + 8 + 5).

Numerator: 150 + 208 + 120 = 478. Denominator: 18. 478 / 18 = 26.56. The longer course pulls the average toward 26, and that is the honest pull.
